# Eno AI / Creative Technology Portfolio

New portfolio focused on AI Product / Creative Technology roles.

## Current phase
Homepage intro prototype only.

### Intro concept
A student-uniform-inspired Eno holds an oversized identity card.
As the viewer scrolls, the card moves toward the camera with strong perspective.
A muted-wine ribbon crosses foreground and background to create depth.
The intro then clears into the main portfolio.

## Visual palette
- Warm white / fog white
- Pearl gray
- Muted wine / dusty rose
- Dark gray typography
